选框架的时候我在几个方案之间比较了一下。

## 候选人

**Next.js** — React 生态最大，但对我来说太重了。一个内容为主的博客不需要 React runtime。

**Nuxt** — Vue 这边类似的角色，同样是用于纯内容站点有点大材小用。

**Astro** — 专门为内容站点设计的框架。默认输出零 JavaScript，支持多框架组件（虽然我这个博客用不到），Markdown 支持开箱即用。

## 选 Astro 的理由

1. **零 JS 输出** — 对博客来说，页面不需要 JavaScript（除了暗色模式切换那几行代码）
2. **Content Collections** — 内置的内容管理，Markdown 文件直接放进去就行
3. **构建快** — 站点小，几乎秒出结果
4. **部署简单** — 纯静态文件，扔到任何静态托管服务上都能跑

对于个人博客来说，简单就是最好的。
